# Virtual Background Images

This directory contains virtual background images for the MusaMeetwebsity video conferencing app.

## Directory Structure

```
backgrounds/
├── office/          - Professional office backgrounds
├── library/         - Library and bookshelf backgrounds
├── nature/          - Natural outdoor scenes
├── living/          - Living room and home interiors
├── architecture/    - Modern buildings and architecture
├── classroom/       - Educational settings
└── creative/        - Unique and artistic backgrounds
```

## Image Requirements

- **Format**: JPG or PNG
- **Resolution**: Minimum 1920x1080 (Full HD)
- **Aspect Ratio**: 16:9
- **File Size**: Keep under 2MB for best performance
- **Quality**: High resolution, well-lit, professional looking

## How to Add Images

1. Download your chosen image
2. Rename it to match the filename in `src/data/backgroundLibrary.js`
3. Place it in the appropriate category folder
4. The app will automatically load it

## File Naming Convention

Use descriptive, kebab-case names:
- ✅ `modern-office-cityview.jpg`
- ✅ `classic-library.jpg`
- ✅ `tropical-beach.jpg`
- ❌ `IMG_1234.jpg`
- ❌ `background.jpg`

## Performance Tips

- Optimize images before adding (use tools like TinyPNG or Squoosh)
- Compress to reduce file size without losing quality
- Use JPG for photographs, PNG for graphics with transparency
- Keep resolution at 1920x1080 or 2560x1440 maximum

## License Compliance

- Only use images you have the right to use
- Check license requirements for each image source
- Some licenses require attribution (add credits if needed)
- When in doubt, use Creative Commons CC0 or public domain images
