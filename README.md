# MusaMeetwebsity 🎥

A modern video conferencing application built with React, featuring virtual backgrounds, screen sharing, and real-time communication.

## Features

- 🎥 High-quality video conferencing
- 🖼️ Virtual backgrounds (26+ professional backgrounds)
- 🌫️ Background blur effects
- 🖥️ Screen sharing with system audio
- 💬 Real-time chat
- 👥 Participant management
- ✋ Raise hand functionality
- 🎙️ Audio/video controls
- 📹 Local recording
- 👤 Person segmentation using MediaPipe

## Technologies

- **Frontend:** React 19, React Router
- **Build Tool:** Vite
- **AI/ML:** MediaPipe Selfie Segmentation
- **Styling:** Custom CSS
